# المساعد الشخصي (نموذج أولي) — Personal AI Agent Prototype

مساعد شخصي متعدد المهام: يقرأ ويدور في ملفاتك، يحفظ ملاحظات، ويدير مهام بذاكرة دائمة — والطلبات المركبة بتتنفذ خطوة خطوة قدامك، وأي إجراء حساس (زي مسح ملف) بياخد موافقتك الأول.

**الواجهة بثلاث لغات: العربية والإنجليزية والتركية** — بتختار اللغة من القايمة فوق، والمساعد بيرد بنفس اللغة المختارة. اختيارك بيتفضل محفوظ في المتصفح.

A local, multi-task personal agent prototype: file reading, search, notes and task management with persistent storage, compound multi-step requests with a visible step trace, plus an approval gate before any sensitive action. Arabic web UI + CLI.

> **الحالة:** نموذج أولي v0.2 — شغال محليًا، وقابل للتطوير.

## إزاي يفكر

```
طلبك ← الموديل يقرر أنهي أداة ← الكود ينفذ الأداة ← النتيجة ترجع للموديل ← الخطوة الجاية ← الرد النهائي
```

- **العقل:** موديل Gemini (مجاني في مستواه الأول) — اختياري.
- **الأدوات:** دوال JavaScript في `tools.js` — الموديل بينده عليها، لكن كودك هو اللي ينفذ.
- **الطلبات المركبة:** طلب زي «اقرأ الملفات وحدد الناقص واعمل مهام» بينفذ على خطوات ورا بعض، وكل خطوة ونتيجتها بتظهرلك في أثر الخطوات.
- **الذاكرة:** المهام في `data/tasks.json` والملاحظات في `data/notes.md` — بيفضل محفوظين بين التشغيلات.
- **بوابة الموافقة:** أي أداة عليها علامة `requiresApproval` بتوقف وتستنى قرارك (زرار في الويب، أو "نعم" في الـ CLI).

## واجهة الويب (الأساسية)

1. ثبّت Node.js من https://nodejs.org (لو مش موجود عندك).
2. افتح مجلد المشروع، كليك يمين ← **Open in Terminal**.
3. شغّل:

```
node server.js
```

4. افتح المتصفح على: **http://127.0.0.1:3000**

هتلاقي شات على اليمين، وعلى الشمال لوحة فيها مهامك وملفاتك وملاحظاتك بتتحدث لوحدها بعد كل رد.

- **السيرفر مقفول على جهازك بس** (127.0.0.1) — مش متاح لحد تاني على الشبكة.
- **مفتاح Gemini بيفضل على السيرفر** في متغير البيئة، ومبيتبعتش للمتصفح أبدًا.

## سطر الأوامر (القديم شغال)

```
node agent.js
```

## وضع التجربة (من غير مفتاح)

من غير مفتاح بيشتغل **بوضع تجربة محلي**: الأدوات شغالة بجد والذاكرة بتحفظ، لكن الردود مش من موديل ذكي — محلل أوامر بسيط يفهم:

| الأمر | اللي بيحصل |
| --- | --- |
| `أضف مهمة: أذاكر C` | يضيف مهمة محفوظة |
| `عرض المهام` | يعرض القايمة |
| `خلصت مهمة 1` | يعلمها مكتملة |
| `ملاحظة: الاجتماع يوم الحد` | يحفظ ملاحظة |
| `ابحث عن قهوة` | يدور في الملفات والملاحظات |
| `عرض الملفات` | يعرض ملفات مجلد العمل |
| `اقرأ welcome.txt` | يقرا الملف |
| `امسح shopping.txt` | يسألك موافقتك قبل المسح |

الطلبات المركبة والردود الحرة محتاجة الوضع الحي.

## الوضع الحي (بمفتاح Gemini مجاني)

1. افتح https://aistudio.google.com بحساب جوجل بتاعك واعمل **API key** (المستوى المجاني فيه حصص يومية محدودة، وبياناته ممكن جوجل تستخدمها في تحسين منتجاتها — فمتبعتش بيانات شخصية حقيقية).
2. في نفس الـ Terminal قبل التشغيل:

```
set GEMINI_API_KEY=مفتاحك_هنا
node server.js
```

(في PowerShell: `$env:GEMINI_API_KEY="مفتاحك_هنا"`)

دلوقتي تقدر تكلمه حر، بما فيه طلبات مركبة زي: «اقرأ كل ملفات مجلد العمل، حدد إيه الناقص، واعمل مهام بيها».

```
node test/run-tests.js
```

## هيكل المشروع

```
core.js       قلب الـ agent المشترك (الحلقة + أثر الخطوات + بوابة الموافقة)
server.js     سيرفر الويب المحلي (127.0.0.1 بس)
agent.js      واجهة سطر الأوامر
tools.js      الأدوات: ملفات، بحث، ملاحظات، مهام + بوابة الموافقة
public/       واجهة الويب (HTML/CSS/JS من غير أي مكتبات)
workspace/    مجلد العمل اللي الـ agent يتعامل معاه
data/         الذاكرة (مش بينترفع على GitHub)
test/         الاختبارات الأوﭽلاين والحية
```
