# المساعد الشخصي (نموذج أولي) — Personal AI Agent Prototype

مساعد شخصي متعدد المهام من سطر الأوامر: يقرأ ويدور في ملفاتك، يحفظ ملاحظات، ويدير مهام بذاكرة دائمة — وأي إجراء حساس (زي مسح ملف) بياخد موافقتك الأول.

A local, multi-task personal agent prototype: file reading, search, notes and task management with persistent storage, plus an approval gate before any sensitive action. Arabic CLI.

> **الحالة:** نموذج أولي v0.1 — شغال محليًا، وقابل للتطوير.

## إزاي يفكر

```
طلبك ← الموديل يقرر أنهي أداة ← الكود ينفذ الأداة ← النتيجة ترجع للموديل ← الرد النهائي
```

- **العقل:** موديل Gemini (مجاني في مستواه الأول) — اختياري في النسخة دي.
- **الأدوات:** دوال JavaScript في `tools.js` — الموديل بينده عليها، لكن كودك هو اللي ينفذ.
- **الذاكرة:** المهام في `data/tasks.json` والملاحظات في `data/notes.md` — بيفضل محفوظين بين التشغيلات.
- **بوابة الموافقة:** أي أداة عليها علامة `requiresApproval` بتوقف وتستنى "نعم" منك.

## التشغيل على ويندوز

1. ثبّت Node.js من https://nodejs.org (لو مش موجود عندك).
2. افتح مجلد المشروع، كليك يمين ← **Open in Terminal** (أو Terminal من القايمة).
3. شغّل:

```
node agent.js
```

## وضع التجربة (من غير مفتاح)

لو شغلته كده من غير مفتاح، هيشتغل **بوضع تجربة محلي**: الأدوات شغالة بجد والذاكرة بتحفظ، لكن الردود مش من موديل ذكي — محلل أوامر بسيط يفهم:

| الأمر | اللي بيحصل |
| --- | --- |
| `أضف مهمة: أذاكر C` | يضيف مهمة محفوظة |
| `عرض المهام` | يعرض القايمة |
| `خلصت مهمة 1` | يعلمها مكتملة |
| `ملاحظة: الاجتماع يوم الحد` | يحفظ ملاحظة |
| `ابحث عن قهوة` | يدور في الملفات والملاحظات |
| `عرض الملفات` | يعرض ملفات مجلد العمل |
| `اقرأ welcome.txt` | يقرا الملف |
| `امسح shopping.txt` | يسألك موافقتك قبل المسح |

## الوضع الحي (بمفتاح Gemini مجاني)

1. افتح https://aistudio.google.com بحساب جوجل بتاعك واعمل **API key** (المستوى المجاني فيه حصص يومية محدودة، وبياناته ممكن جوجل تستخدمها في تحسين منتجاتها — فمتبعتش بيانات شخصية حقيقية).
2. في نفس الـ Terminal قبل التشغيل:

```
set GEMINI_API_KEY=مفتاحك_هنا
node agent.js
```

(في PowerShell: `$env:GEMINI_API_KEY="مفتاحك_هنا"`)

دلوقتي تقدر تكلمه حر: "ضيفلي مهمة أسلم مشروع البرمجة" أو "دورلي في الملفات على كلمة اجتماع".

## هيكل المشروع

```
agent.js      الحلقة والواجهة (CLI)
tools.js      الأدوات: ملفات، بحث، ملاحظات، مهام + بوابة الموافقة
workspace/    مجلد العمل اللي الـ agent يتعامل معاه
data/         الذاكرة (مش بينترفع على GitHub)
```

## المراحل الجاية

1. ✅ القلب + أدوات القراءة والمهام والملاحظات (النسخة دي)
2. بحث على الويب مع تلخيص بالمصادر
3. أدوات كتابة أكتر وراء بوابة الموافقة
4. واجهة تليجرام أو ويب (عربي/إنجليزي/تركي)
